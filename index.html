Free. Independent. Reliable

Minimal Source based linux

Fir Linux is a new minimal source based distribution.
System config and packages are declared in config.fir in /etc/fir
Fir is declarative not reproducible. Inspired by nix and gentoo, Fir aims to create an operator respecting system. built to be minimal.

No systemd!

Fir uses openrc by default, other init support is planned but not guaranteed.

Contributions welcome!

Matrix channel in the works!
