FIR

Free. Independent. Reproducible.

FIR is a small, independent Unix-like operating system. Its package system is inspired by Nix: you describe the system you want, and FIR builds it the same way every time.

The base system is deliberately small — a set of core utilities, a window manager for Xorg, and the pieces needed to get to a shell and work. FIR is minimal by default and opinionated on purpose: it makes a few firm choices, documents them, and does not offer four overlapping ways to do the same thing.

FIR is free software, released under the GNU GPLv3. Development happens in the open. (Status: pre-alpha — there is no installable release yet.)

## Principles

F — Free

You may run FIR, study it, share it and modify it. Every part of the system ships under the GNU GPLv3. No telemetry, no accounts, no lock-in.

I — Independent

FIR is built and maintained by its own contributors. No company and no parent distribution decides where it goes — inspired by Nix, owned by the people who run it.

R — Reproducible

Same inputs, same outputs, bit for bit. Anyone can rebuild the system from source and verify it matches what everyone else got.

## What's in the box

Core utilities

A compact set of Unix utilities. Each one does one thing and composes with pipes. Small enough to read in an afternoon.

Window manager

A simple window manager for Xorg: one binary, one config file, no daemon you did not ask for.

Package system

Declarative and reproducible. Pin your inputs, build the closure, get the same system every time.

## Example session

Planned command interface — nothing to run yet.

$ fir build ./system.nix   # evaluate and build
$ fir switch               # activate the build
$ fir rollback             # go back; reproducible, so this is safe
